PANDUAN SINGKAT - APLIKASI LAUNDRY
===================================

Jalankan file .bat secara berurutan. Cukup klik dua kali.


URUTAN PEMAKAIAN PERTAMA KALI
-----------------------------
1. 1-INSTALL.bat     Memasang semua komponen. Perlu internet.
2. 2-MIGRATE.bat     Menyiapkan database dan data awal.
3. 3-JALANKAN.bat    Menjalankan aplikasi, browser terbuka otomatis.


PEMAKAIAN SEHARI-HARI
---------------------
Cukup klik 3-JALANKAN.bat.
Jangan tutup jendela hitam selama aplikasi dipakai.

Untuk menghentikan aplikasi: tekan Ctrl+C di jendela itu, lalu Y.


MEMBUKA APLIKASI KE INTERNET UNTUK DOSEN
-----------------------------------------
1. Jalankan 3-JALANKAN.bat dan biarkan jendelanya tetap terbuka.
2. Klik 5-NGROK.bat.
3. Salin alamat https://....ngrok-free.app yang muncul.
   Itu alamat yang dibagikan ke dosen.

Alamat publik itu juga otomatis ditulis ke APP_URL di file .env,
supaya link pesanan di WhatsApp bisa dibuka dari HP pelanggan.
Bila aplikasi sudah berjalan sebelum ngrok dinyalakan, tutup lalu
jalankan lagi 3-JALANKAN.bat agar alamat baru terpakai.

Butuh akun ngrok gratis di https://ngrok.com.
Sekali saja, jalankan di Command Prompt:
   ngrok config add-authtoken TOKEN_ANDA

Bila port aplikasi bukan 3000, jalankan dari Command Prompt:
   5-NGROK.bat 3001


BILA ADA VERSI BARU
-------------------
1. Tutup aplikasi yang sedang berjalan.
2. Klik 4-UPDATE.bat.
3. Klik 3-JALANKAN.bat.


YANG PERLU DIPASANG DI KOMPUTER
-------------------------------
- Node.js versi LTS       https://nodejs.org
- MySQL atau XAMPP        https://www.apachefriends.org
- Git                     https://git-scm.com


BILA MUNCUL PESAN GAGAL
-----------------------
- "MySQL belum menyala"      -> nyalakan MySQL di XAMPP Control Panel.
- "DATABASE_URL salah"       -> buka file .env, periksa password MySQL.
- "Node.js belum terpasang"  -> pasang Node.js, lalu ulangi 1-INSTALL.bat.

Detail lengkap ada di README.md.
